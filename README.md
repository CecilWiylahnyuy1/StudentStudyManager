
  Student Study Manager

A web app to help students manage tasks, notes, and their study timetable.

Features
- Add, view, and manage tasks with due dates
- Save notes by subject
- Build a weekly study timetable

Tech Stack
- Node.js + Express (backend API)
- HTML, CSS, JavaScript (frontend)

How to Run
1. Clone this repo
2. Run `npm install`
3. Run `node server.js`
4. Open `http://localhost:3000` in your browser

API Routes
- `GET /tasks`, `POST /tasks`, `PUT /tasks/:id`, `DELETE /tasks/:id`
- `GET /notes`, `POST /notes`, `PUT /notes/:id`, `DELETE /notes/:id`
- `GET /timetable`, `POST /timetable`, `PUT /timetable/:id`, `DELETE /timetable/:id`
